ForenIQ

AI-assisted analysis of Cellebrite UFDR phone extractions. Every sentence it writes is checked against the records it cites, and every action is sealed in a hash-chained audit log.

All data on this page is synthetic. "Operation Kaveri" is a fictional case generated for testing. The names, phone numbers and bank details are invented and belong to no real person. The figures below come from one recorded run of the prototype on a clean Python 3.12 install.

Search

Plain questions, in English or Hinglish

13 test questions were scored against ground truth from the data generator. Keyword search only matches an exact phrase, so natural questions return nothing. Meaning-based (semantic) search finds relevant records; hybrid mixes both rankings with reciprocal rank fusion. P@5 is the share of the top five results that are relevant. MRR rewards putting the first relevant result near the top.

Anomaly detection

Unusual activity, compared with each phone's own normal

An Isolation Forest scores six-hour windows on four features: message and call count, share of night-time activity, share of deleted records, and how spread out the contacts are. Each phone is compared with its own baseline. Each flag says which features drove it. The output describes statistics only; it makes no claim about guilt.

Citation verifier

No sentence gets through without its evidence

The verifier is plain rule-based code with no AI model. A factual sentence must carry a citation tag, and the tag must point to a record that exists. Every name, amount, date and phone number in the sentence must also appear in that record. A sentence that fails is rewritten once, then removed. Chain of custody

A tamper-evident audit log

Every upload, search, answer and report is logged. Each log entry stores the hash of the one before it, so editing or deleting any entry breaks the chain from that point on. The report records the case's file hashes and the report hash, as Section 63 of the Bharatiya Sakshya Adhiniyam, 2023 requires.

Try it

Run it on your own machine

Needs Python 3.12 and Node.js 20 or newer. Windows users can run the numbered .bat files in the project folder instead.

git clone https://github.com/suhanii-an/AI-based-UFDR-Analysis-tool-digital-forensics-.git
cd AI-based-UFDR-Analysis-tool-digital-forensics-
./setup_mac_linux.sh                 # venv + pinned packages + frontend
# start the API and UI (see RUN_DEMO.md), then load the demo case:
python scripts/demo_operation_kaveri.py
